# M1-D：UR5e 夹挤后的动作试验

日期：2026-10-03。**抬高 wall_align、拆开退／抬／转、横向侧移均已实测。横向侧移保留了真实取豆并显著降低腕部峰值，但仍未通过原数值对照；本轮不采用任何候选，不进入双机器人完整验收或冻结。**

本轮接续 [bean_011 顺序排查](m1d_ur5e_seed0_diagnosis.md)，只研究 UR5e seed 0。正式接触参数、控制器、保护、验收阈值和轨迹目标未修改。实验驱动只在自身进程中替换目标序列，物理仍由现有 `step_physics()` 推进；不在运行中编辑 Bean 的 qpos/qvel。

## 1. 先纠正动作时序和承托假设

原夹挤峰值发生于 12.675 s，而原 wall_align 从 13.532 s 才开始。因此，仅抬高这个后续目标不能预防之前的夹挤；先从同一 12.40 s 完整状态检验它能否解夹。该状态所有豆仍由碗承托，未有豆得到勺子承托。bean_003 虽在勺头投影内，也不能视为已取豆。局部成功条件必须同时包含解夹和真实承托，不能只看力变小。

## 3. 横向侧移：局部成功仍不能代替初态复验

从同一 12.40 s 状态保持 x/z/姿态，沿世界 −y 侧移 3 mm；继续 sweep 时保持该 y 偏移，之后恢复原 wall_align 8.5 mm 和全部后续阶段。三组均按原 M1-C 拾取判据取到 bean_003，腕部峰值为 0.3134／0.3400／0.3351 N，最大穿透记录为 0。半步长全部数值指标通过；200 iterations 的豆—勺冲量为 0.6986 Ns，基准 0.2976 Ns，差 0.4009 Ns 超过 0.0595 Ns 门槛。

随后把动作改为可从初态执行的碗相对路径：entry 后先前进 3.7 mm，再侧移 −y 3 mm，完成保持偏移的 sweep，再执行原后续阶段。相同 10.40 s 状态复验及从正式 episode_reset 状态执行均真实取到 bean_003，但均未通过三组对照：

| 起点 | 基准腕部 N | 半步长 N | 200 iterations N | 数值判定 |
| --- | ---: | ---: | ---: | --- |
| 同一 12.40 s 状态解夹 | 0.3134 | 0.3400 | 0.3351 | 200 iterations 冲量失败 |
| 同一 10.40 s 状态，前进 3.7 mm 后侧移 | 0.4546 | 0.1555 | 0.4846 | 半步长峰值、200 iterations 冲量失败 |
| episode_reset，前进 3.7 mm 后侧移 | 0.2239 | 0.1515 | 0.4652 | 两组峰值及冲量失败 |

检查点运行继承此前的 monitor 历史，只作为局部诊断；从 episode_reset 执行的结果用于评估完整候选取豆路径。两者不能互相替代。几何审计确认该碗相对候选在 Panda／UR5e 的目标一致（最大差 4.2e-17 m），原 entry 和 sweep 后目标保持不变；这不构成 Panda 实际运行通过。

## 4. 仅提前侧移触发位置：3.7 → 2.5 mm

3.7 mm 版本的峰值证据包含侧移前 sweep_initial 阶段的 bean_011 接触，因此只把触发前进量改为 2.5 mm，侧移仍为 3 mm，其他目标及接触参数不变。从同一正式 episode_reset 状态完整运行三组：

| 指标 | 基准 | 半步长 | 200 iterations |
| --- | ---: | ---: | ---: |
| 原取豆判据／实际 ID | 通过／bean_003 | 通过／bean_003 | 通过／bean_003 |
| 腕部峰值 N | 0.06945 | 0.06620 | 0.07870 |
| 豆—勺峰值 N | 0.23635 | 0.12930 | 0.23673 |
| 豆—勺冲量 Ns | 0.34886 | 0.28860 | 0.73918 |
| 豆—豆冲量 Ns | 0.12251 | 0.15232 | 0.12242 |
| 最大穿透 m | 0 | 0 | 0 |

全部失败项，而非只记录断言遇到的第一项：

- 半步长豆—勺峰值差 **0.10705 N > 0.05 N**；豆—豆冲量差 **0.02981 Ns > 0.02450 Ns**。
- 200 iterations 豆—勺冲量差 **0.39032 Ns > 0.06977 Ns**。
- 腕部峰值、其他语义接触指标和 TCP 对照均通过；半步长最大 TCP 位置／旋转差约 23.2 µm／0.000376 rad。

原每小步 monitor 的峰值及冲量决定数值判定。另用 10 ms 轨迹作阶段定位：200 iterations 增加的豆—勺接触幅值积分主要位于 wall_45／wall_30／wall_15，最终 pickup_hold 的三组采样积分接近 0.052 Ns。这个采样积分不是验收冲量，也不是矢量冲量，不能用于放行。

基准单接触证据的较大豆—勺力已主要转为 **bean_003**：16.389 s 的 wall_45 接触约 0.1092 N，15.873 s 另一接触约 0.1079 N；半步长仍包含 12.103 s sweep_initial 的 bean_011 接触约 0.0662 N。腕部力低不能排除多接触幅值的差异；本轮没有证明 bean_003 的这些接触一定属于夹挤，也没有证明同状态求解错误。
