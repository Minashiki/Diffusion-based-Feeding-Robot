# 单豆 M4 执行顺序

以 `SimModelPlann.md` 第 12 节和 `m4_interfaces.md` 为当前契约。固定碗中单豆自然初态，原 M1/M3 物理参数和事件冻结记录保留。

1. 迁移只读几何、12 点舀取、观测与证据字段，通过单位、限幅、无写入、整数时钟和重放检查。
2. 真实取餐固定重复至少 3 次，再用 10 个独立调试场景确认；从实际取餐连续完成运输、静态／动态交付、撤离和恢复。
3. 仅在 calibration 检查 ±1° 舀取俯仰、±5 mm 抬升、±1° 运输俯仰候选及组合。失败保留，范围调整后重新调试，不占用正式验收种子。
4. 完成旧输出清理及代码／配置／文档变更，将 `teacher_status` 设为 frozen，保存新目录的全部输入、父冻结引用、独立种子与收敛用例。
5. Panda 正常 ≥95/100、恢复 10/10；UR5e 正常／恢复各 5/5。全部回合重放、同初态收敛、成功 viewer、完整 M1/M3 回归和 pytest 通过才放行教师。
6. 采集 Panda 正常／恢复各 train/validation/test=100/15/15，失败全部保留重放。split、mask、归一化、配额及 hash 通过后发布 M4 冻结清单和审计，再进入 M5。

正式状态仅由 `outputs/single_bean/v1/m4/` 的匹配报告确认。局部调试、预置食物、观察分支及历史模型成绩均不替代完整门槛。
